개인정보처리방침

Scriv Camera는 모니터·노트북 화면의 코드, 로그, 문서 같은 텍스트를 촬영해 기기에 저장하고 사용자가 원할 때 공유하는 Android 카메라 앱입니다.

패키지 이름: me.jeongdo.scrivcamera

최종 업데이트: 2026-09-10

핵심 원칙: Scriv는 촬영 이미지를 개발자 서버로 전송하지 않습니다. 계정·로그인·앱 전용 클라우드가 없으며 핵심 촬영 기능은 오프라인으로 동작합니다. 외부 앱으로 이미지를 전달하는 동작은 사용자가 Share를 명시적으로 실행했을 때만 시작됩니다.

1. 권한

Scriv는 핵심 촬영을 위해 Android의 카메라 권한을 사용합니다.

  • 카메라 — 미리보기와 JPEG 촬영에 사용합니다.
  • 위치 — 요청하지 않습니다.
  • 마이크 — 요청하지 않습니다.
  • 연락처·계정 — 요청하지 않습니다.
  • 네트워크 — 현재 앱은 인터넷 권한을 요구하지 않습니다.

2. 촬영 이미지와 저장

촬영한 JPEG는 Android MediaStore를 통해 기기의 공유 사진 영역 Pictures/Scriv에 저장됩니다.

촬영 이미지 자체를 Scriv 개발자가 운영하는 서버로 자동 업로드하거나 수집하지 않습니다.

저장된 사진은 갤러리나 Android 미디어 관리 기능을 통해 사용자가 직접 확인하거나 삭제할 수 있습니다. 앱을 삭제해도 공유 미디어 영역에 저장된 사진은 Android의 미디어 보관 정책에 따라 남아 있을 수 있습니다.

3. 공유와 외부 앱

Scriv의 Share 기능은 사용자가 명시적으로 실행했을 때 Android Sharesheet를 엽니다. 사용자가 선택한 외부 앱에는 해당 촬영 이미지의 읽기 가능한 content URI가 전달될 수 있습니다.

이미지가 외부 앱으로 전달된 이후의 보관·전송·처리는 선택한 앱 또는 서비스의 개인정보처리방침을 따릅니다. Scriv는 공유 대상을 자동으로 선택하거나 백그라운드에서 자동 공유하지 않습니다.

4. 앱 설정과 진단 정보

  • 마지막 카메라 모드와 그리드, 화면 꺼짐 방지, 햅틱, 볼륨키 셔터, 타이머 같은 설정은 기기 내부 DataStore에 저장될 수 있습니다.
  • Info 화면은 camera id, focal length, 지원 범위, 노출값, 화면 밝기 통계, preview/capture 지연 같은 기기 진단값을 표시할 수 있습니다.
  • COPY INFO는 사용자가 직접 누를 때 이 진단 텍스트를 Android 클립보드에 복사합니다.

Scriv의 COPY INFO 진단에는 촬영 이미지 내용이나 위치 데이터가 포함되지 않도록 설계되어 있습니다. Android 클립보드에 복사된 이후의 접근·보관은 기기와 사용 중인 다른 앱의 정책 영향을 받을 수 있습니다.

5. 서버, 계정, 광고 및 분석

현재 Scriv는 개발자가 운영하는 사용자 계정 시스템, 이미지 저장 서버, 앱 전용 클라우드 백업, 광고 SDK 또는 사용자 행동 분석 SDK를 사용하지 않습니다.

향후 실제 앱 동작이나 사용 SDK가 바뀌어 데이터 처리 범위가 달라지는 경우 이 개인정보처리방침도 함께 갱신합니다.

6. Android 시스템 백업

기기와 Google 계정의 Android 백업 설정에 따라 앱 내부의 일부 설정이 시스템 백업 또는 기기 이전 기능에 포함될 수 있습니다. 이 처리는 Android/Google 플랫폼 기능에 의해 수행되며 Scriv 개발자가 별도 백업 서버를 운영하는 방식이 아닙니다.

7. 데이터 삭제

  • 촬영 사진 — 사용자가 갤러리 또는 Android 미디어 관리 기능에서 삭제할 수 있습니다.
  • 앱 내부 설정 — Android의 앱 데이터 삭제 또는 앱 제거로 삭제할 수 있습니다. 시스템 백업 설정에 따라 재설치·기기 이전 시 일부 설정이 복원될 수 있습니다.
