Book Marker · Privacy Policy

개인정보처리방침

Book Marker는 웹사이트의 URL 구조를 개인용 바로가기 및 검색 템플릿으로 저장하고, 사용자가 원하는 페이지·검색·필터 상태로 빠르게 다시 이동할 수 있도록 돕는 Chrome 확장 프로그램입니다.

핵심 원칙: Book Marker는 사용자 데이터를 개발자의 외부 서버로 수집하거나 전송하지 않습니다. 저장된 바로가기, 설정 및 최근 실행 기록은 사용자의 브라우저 로컬 저장소에 보관됩니다.

1. 처리하는 사용자 데이터

Book Marker는 기능 제공을 위해 다음 정보를 기기 내에서 처리할 수 있습니다.

  • 현재 탭의 URL 및 페이지 제목 — 사용자가 현재 페이지를 바로가기 또는 검색 템플릿으로 만들 때 URL 구조를 분석하기 위해 사용합니다.
  • 사용자가 저장한 URL 템플릿 — 경로(Path), 쿼리(Query), 태그, 이름, 계층 관계, 정렬 순서 등의 바로가기 정보를 포함할 수 있습니다.
  • 최근 실행 기록 — 사용자가 실행한 바로가기, 입력값, 생성된 URL 및 실행 시각이 포함될 수 있습니다.
  • 사용자가 명시적으로 선택한 웹페이지 텍스트 — 우클릭의 “Book Marker로 검색” 기능을 사용한 경우에만 선택한 텍스트를 저장된 검색 템플릿의 입력값으로 사용합니다.
  • 확장 프로그램 설정 — 테마 등 Book Marker의 사용자 설정을 저장합니다.

2. 데이터 사용 목적

처리되는 데이터는 다음과 같은 Book Marker의 핵심 기능 제공에만 사용됩니다.

  • 현재 웹페이지의 URL 구조 분석
  • 개인용 바로가기 및 동적 검색 템플릿 생성·저장
  • 저장된 템플릿을 통한 검색, 필터 및 페이지 이동
  • 바로가기 검색, 태그 분류, 계층 관리 및 수동 정렬
  • 최근 실행 내역 표시
  • 사용자가 선택한 텍스트를 지정한 검색 사이트에서 검색

Book Marker는 광고 프로파일링, 신용 평가, 대출 심사 또는 확장 프로그램의 단일 목적과 관련 없는 목적으로 사용자 데이터를 사용하지 않습니다.

3. 데이터 저장 및 외부 전송

저장된 템플릿, 최근 실행 기록 및 설정은 Chrome 확장 프로그램의 storage.local 영역에 저장됩니다. Book Marker 개발자는 별도의 서버를 통해 이 데이터를 수집하지 않습니다.

단, 사용자가 검색 바로가기를 실행하면 사용자가 입력하거나 선택한 검색어가 생성된 URL의 일부로 포함될 수 있으며, 해당 URL을 여는 과정에서 그 검색어가 사용자가 선택한 대상 웹사이트로 전달될 수 있습니다. 이는 사용자가 명시적으로 요청한 검색 또는 이동을 수행하기 위한 동작입니다.

4. 제3자 제공 및 판매

Book Marker는 사용자 데이터를 판매하지 않습니다.

또한 사용자가 직접 선택한 사이트에서 검색 또는 페이지 이동을 실행하는 데 필요한 경우를 제외하고, 사용자 데이터를 개발자 또는 제3자에게 전송하거나 제공하지 않습니다.

5. 데이터 보관 및 삭제

사용자 데이터는 사용자가 Book Marker에서 직접 삭제할 때까지 브라우저 로컬 저장소에 남아 있을 수 있습니다.

  • 저장한 바로가기는 Book Marker 설정 화면에서 삭제할 수 있습니다.
  • 최근 실행 기록은 “최근 기록 비우기” 기능으로 삭제할 수 있습니다.
  • 확장 프로그램을 제거하면 Book Marker가 사용하는 확장 프로그램 로컬 데이터도 더 이상 Book Marker에서 사용할 수 없습니다.

6. 보안

Book Marker는 사용자 데이터를 외부 서버에 저장하지 않고 브라우저가 제공하는 확장 프로그램 전용 로컬 저장소를 사용하여 불필요한 외부 전송을 최소화합니다. 확장 프로그램은 기능 수행에 필요한 범위의 브라우저 권한만 사용하도록 유지합니다.

7. 개인정보처리방침의 변경

Book Marker의 기능이나 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침도 함께 업데이트할 수 있습니다. 중요한 변경이 있는 경우 이 페이지의 “최종 업데이트” 날짜를 변경합니다.
